Distribution note
-----------------
The engine components above are merged into a single static library
(librime, glog, LevelDB, marisa-trie, OpenCC, RapidJSON, darts-clone,
yaml-cpp, Boost.Regex, librime-lua, Lua, librime-octagram, librime-predict,
and the project's C bridge). The final binary only contains the object files
the linker pulls in; these notices list the linked components and bundled
data.

The built-in dictionary (songyan_basic.dict.yaml) is original to this project
and contains no upstream dictionary corpus. The bundled songyan_flypy schema
adapts the ordered Flypy rules from rime-clover-flypy (LGPL-3.0) and
rime-double-pinyin (GPL-3.0); its header records the project modifications.
The generated keyboard_*.schema.yaml companions are derived from
songyan_flypy and songyan_quanpin and point back to that header. No rime-ice
dictionary data ships.

The app bundles OpenCC 1.1.9 conversion data: 16 compiled dictionaries and 14
JSON configs sourced from the pinned OpenCC release. The upstream project
distributes these under Apache-2.0, whose full text is
opencc-1.1.9-LICENSE.txt. The built-in schemes do not activate OpenCC;
imported schemes may use these data files.

The nine-key t9_processor (rime_t9_processor.cc and rime_t9_keys.h in the
engine sources) is original project code licensed under GPL-3.0-only (root
LICENSE). It is compiled into the bundled engine and uses the public
Processor, Speller and module registry interfaces of librime 1.17.0
(BSD 3-Clause, librime-1.17.0-LICENSE.txt).
